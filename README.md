**PCとスマホのあいだで、ブラウザだけでファイルを送り合う。**

## 概要

**LanDrop** は、PCで動かすアプリに、スマホのブラウザから接続してファイルを送受信します。
iPhoneは **Safari**、Androidは **Chrome** でQRコードを読み取るだけで使えます。PCでは
**PCの画面** が開き、ファイルをドロップしてスマホへ送ったり、スマホから届いたファイルを見たりできます。

通信するのは **同じWi-Fi（同じルーター）につながったPCとスマホのあいだ** だけです。インターネットを
経由しません。画面はHTML・CSS・素のJavaScriptで作っており、CDNや外部フォントを使わないため、
インターネットにつながっていないLANでも動きます。

| 機能 | 内容 |
| --- | --- |
| **PCの画面** | 起動すると、アドレスバーのないアプリ用の窓が開く。QRコード、スマホへ送るファイル、届いたファイルを1つの画面で扱える |
| **PC → スマホ** | PCの画面にファイルをドロップすると共有フォルダにコピーされ、スマホの「受け取る」に数秒で表示される。タップで保存する |
| **スマホ → PC** | 複数のファイルを選び、1ファイルずつ順番に送る。ファイルごとに進捗と「送信待ち・送信中・完了・失敗」を表示し、失敗したものだけ再送できる |
| **届いたファイル** | PCの画面にサムネイル付きで並ぶ。受信中の進み具合と新着の「NEW」を表示し、画像と動画はその場で大きく表示できる |
| **QRコードで接続** | PCの画面とターミナルにQRコードを表示する。読み取るとその場で認証され、トークンを含まないURLへ移動する |
| **同名ファイル** | 上書きせず `写真 (1).jpg` のように自動で改名する。同時に送っても名前がぶつからない |
| **大きなファイル** | 受信データを少しずつ `.part` ファイルに書き込み、完了後に正式な名前へ変更する。ファイル全体をメモリに読み込まない（既定の上限は1ファイル10GB） |
| **自動停止** | PCの画面を閉じるか、30分間操作がなければ停止する。データの送受信が続いている間は停止しない |
| **アプリ** | Windowsは `LanDrop.exe`、macOSは `LanDrop.app` にまとめられ、ダブルクリックで起動できる |

> 通信はHTTPで、**暗号化されません**。公共Wi-Fi・ホテル・カフェなど、知らない人と共有するネットワークでは使わないでください。

## 対応環境

| 項目 | 対応 |
| --- | --- |
| **PC** | Windows 11（日本語版）、macOS |
| **PCの画面** | Microsoft Edge または Google Chrome のアプリ用の窓で開く。どちらもなければ、既定のブラウザで開く |
| **スマホ** | iPhone（Safari）、Android（Chrome） |
| **Python** | 3.11 以上（3.11.17 と 3.15.0 で自動テスト済み） |
| **主なライブラリ** | FastAPI / Uvicorn / qrcode（`requirements.txt`。FastAPI 0.162・Uvicorn 0.54・qrcode 8.2 で確認） |
| **アプリにまとめる** | PyInstaller と Pillow（`requirements-build.txt`。PyInstaller 6.22・Python 3.15.0 でWindows版を確認） |

WSL2 を使っているWindowsでも、**WSLの中ではなく、Windowsで** 起動してください。WSLの中で起動すると、
スマホから届かない仮想ネットワークのアドレスで待ち受けてしまいます。

## セットアップ

### アプリとして使う（exe / .app）

一度アプリにまとめれば、次からはダブルクリックで起動できます。アプリは、それを使うOSの上で作ります
（WindowsでmacOS用は作れません）。

**Windows（PowerShell）**

```powershell
cd "C:\path\to\LanDrop"    # このフォルダの場所に合わせて変更
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements-build.txt
.\.venv\Scripts\python.exe packaging\build.py
```

`dist\LanDrop.exe` ができます。これをダブルクリックすると、黒い窓（ログとQRコードを表示する）と
PCの画面が開きます。デスクトップに置くときは、`LanDrop.exe` を右クリック > 送る > デスクトップ
（ショートカットを作成）を選んでください。`LanDrop.exe` だけを別の場所へ移しても動きます。

> 初めて起動したとき、「Windows セキュリティの重要な警告」で LanDrop の通信を許可するか聞かれることがあります。自宅などの **プライベート ネットワーク** だけを許可してください。LanDrop がファイアウォールの設定を自動で変更することはありません。
>
> 自分で作った exe はそのまま起動できます。ほかの人が作った exe をダウンロードして使うと、「WindowsによってPCが保護されました」と表示されることがあります（署名していないため）。

**macOS（ターミナル）**

```bash
cd ~/path/to/LanDrop    # このフォルダの場所に合わせて変更
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements-build.txt
.venv/bin/python packaging/build.py
```

`dist/LanDrop.app` ができます。ダブルクリックするとPCの画面が開きます。ターミナルは開かず、表示は
`~/LanDrop/LanDrop.log` に残ります。起動できなかったときは、その旨をダイアログで知らせます。

> macOS版のアプリは、まだmacOSの実機で確かめていません。LANのアドレスを1つに決められないときは、アプリからは選べないため、ターミナルで `dist/LanDrop.app/Contents/MacOS/LanDrop --ip <アドレス>` のように起動してください。

### Pythonから起動する

アプリにまとめずに、そのまま起動することもできます。

**Windows（PowerShell）**

```powershell
cd "C:\path\to\LanDrop"    # このフォルダの場所に合わせて変更
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python -m landrop
```

`Activate.ps1` が「このシステムではスクリプトの実行が無効」と表示されて動かないときは、仮想環境を
有効にせず、仮想環境の Python を直接使えます（実行ポリシーを変更する必要はありません）:

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m landrop
```

**macOS（ターミナル）**

```bash
cd ~/path/to/LanDrop    # このフォルダの場所に合わせて変更
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python -m landrop
```

> macOSのファイアウォールが有効なときは、「受信接続を許可しますか？」と表示されたら「許可」を選んでください。

2回目からは、仮想環境を有効にして（Windowsは `.\.venv\Scripts\Activate.ps1`、macOSは
`source .venv/bin/activate`）`python -m landrop` を実行するだけです。

## 使い方

| 手順 | 操作 |
| --- | --- |
| **1. 起動** | `LanDrop.exe`（`LanDrop.app`）をダブルクリックするか、`python -m landrop` を実行する。PCの画面が開き、QRコードが表示される |
| **2. 接続** | スマホのカメラでPCの画面のQRコードを読み取り、表示されたリンクを開く。読めないときは、PCの画面の「URLをコピー」で写したURLをスマホに送るか、ターミナルに表示されたURLをスマホのブラウザに入力する |
| **3. スマホへ送る** | PCの画面の「スマホへ送る」にファイルをドロップする（「ファイルを選ぶ」でも選べる）。スマホの「受け取る」に数秒で表示されるので、タップして保存する |
| **4. PCへ送る** | スマホの「送る」タブの「ファイルを選んで送る」で、複数のファイルを選ぶ。届いたファイルは、PCの画面の「届いたファイル」に表示される |
| **5. 終了** | PCの画面の「停止」を押すか、PCの画面を閉じる。ターミナルで `Ctrl+C` を押しても止まる。30分間操作がなければ自動で停止する |

### PCの画面

| 場所 | できること |
| --- | --- |
| **上部** | PC名とアドレス、自動停止までの時間、「停止」 |
| **スマホで接続** | QRコードと「URLをコピー」 |
| **フォルダ** | 共有フォルダと受信フォルダの場所。「開く」でエクスプローラー（Finder）を開く |
| **スマホへ送る** | ドロップしたファイルを共有フォルダにコピーし、進み具合を表示する。共有中のファイルの一覧と「フォルダで表示」 |
| **届いたファイル** | 大きく表示と一覧表示を切り替えられる。受信中の進み具合、新着の「NEW」。画像と動画はクリックで大きく表示し、ほかは「フォルダで表示」でエクスプローラー（Finder）を開く |

共有フォルダは `~/LanDrop/share`、受信フォルダは `~/LanDrop/received` です。`~` は、Windowsでは
`C:\Users\<ユーザー名>`、macOSでは `/Users/<ユーザー名>` です（このプロジェクトのフォルダの中ではありません）。
フォルダは初回の起動時に自動で作られます。共有フォルダに直接ファイルを置いても、スマホに表示されます。

スマホから送ったファイルは、スマホの画面には一覧表示しません。届いたファイルはPCでだけ確認できます。
QRコードのURLは起動のたびに変わるため、再起動したらQRコードを読み取り直してください。

## 起動オプション

| オプション | 既定値 | 説明 |
| --- | --- | --- |
| `--ip` | 自動検出 | 待ち受けるLANのIPv4アドレス。1つに決められないときは、起動時に候補から選べる |
| `--port` | `8765` | 待ち受けるポート番号。省略したときに使用中なら、近くの空きポートを探す。指定したポートが使用中ならエラーで終了する |
| `--share` | `~/LanDrop/share` | スマホへ渡すファイルを置くフォルダ。直下のファイルだけを表示する |
| `--received` | `~/LanDrop/received` | スマホから届いたファイルの保存先。共有フォルダとは別のフォルダにする |
| `--max-size` | `10GB` | スマホから受け取る1ファイルの上限。`500MB`・`2GB`・`1024`（バイト）のように指定する。1KB = 1024バイト |
| `--timeout` | `30` | 無操作が続いたら自動停止するまでの分数。`0` で自動停止しない |
| `--no-open` | — | 起動時にPCの画面を開かない。PCの画面のURLはターミナルに表示される |
| `--version` | — | バージョンを表示する |

使用例（アプリなら `python -m landrop` の代わりに `LanDrop.exe` を使う）:

```bash
python -m landrop --ip 192.168.1.10 --port 9000
python -m landrop --share "D:\共有" --max-size 2GB --timeout 60
python -m landrop --help
```

アドレスを自動で選ぶときは、WSL・Hyper-V・Docker・VirtualBox・VMware・VPN（WireGuard、Tailscale、
OpenVPN など）・ループバック・リンクローカル（`169.254.x.x`）のアダプターを除外し、プライベート
アドレス（`192.168.x.x`、`10.x.x.x`、`172.16〜31.x.x`）のうち既定ゲートウェイを持つものを選びます。
Windowsでは読み取り専用の PowerShell コマンド（`Get-NetIPAddress`、`Get-NetAdapter`、`Get-NetRoute`、
`Get-NetConnectionProfile`）、macOSでは `ifconfig` の結果を使います。1つに決められないときは、候補を
番号付きで表示して選べます。

## セキュリティ

> **HTTPの通信は暗号化されません。** 同じネットワークにいる人に、送受信するファイルの中身を読み取られるおそれがあります。公共Wi-Fi・ホテル・カフェ・イベント会場などでは使わず、参加している人が分かっているネットワークでだけ使ってください。

| 対策 | 内容 |
| --- | --- |
| **起動ごとのトークン** | 起動のたびに `secrets.token_urlsafe(32)` でトークンを作り、QRコードのURLに含める。照合には `secrets.compare_digest` を使う |
| **Cookieでの認証** | トークンが正しければ HttpOnly・SameSite=Lax のCookieを発行し、トークンを含まないURLへリダイレクトする。Cookieの値はトークンとは別の乱数にしている |
| **未認証の拒否** | Cookieのない要求には、ファイル名・フォルダ構成・PC名を返さない |
| **待ち受けるアドレス** | `0.0.0.0` ではなく、選んだLANのアドレスだけで待ち受ける |
| **PCの画面** | `127.0.0.1` だけで待ち受ける別のソケットから使う。スマホなど他の機器からの要求には、PCの画面のパスでも 404 を返す。スマホ用とは別のトークンと、SameSite=Strict のCookieで認証する |
| **ファイルを開かない** | 届いたファイルを実行したり開いたりする操作は作っていない。PCの画面で表示するのは画像と動画だけで、`Content-Security-Policy: sandbox` を付けて返す。HTMLやSVGは表示しない。ほかのファイルは「フォルダで表示」でエクスプローラー（Finder）を開くだけにしている |
| **Hostヘッダーの検証** | `TrustedHostMiddleware` で、待ち受けているIPアドレスと `localhost` 以外を拒否する（DNSリバインディング対策） |
| **ほかのサイトからの要求** | CORSを許可しない。送信や操作を受けるときは、`Origin` がLanDrop自身のページかどうかを確認する |
| **応答ヘッダー** | `X-Content-Type-Options: nosniff`、`Content-Security-Policy`、`X-Frame-Options: DENY`、`Referrer-Policy: no-referrer` を付ける。ダウンロードは `Content-Disposition: attachment`（RFC 5987形式の `filename*` 付き）で返す |
| **ログ** | Uvicornのアクセスログを無効にし、トークンをログに残さない。トークン入りのURLは、起動時に1回だけ表示する |
| **パストラバーサル** | ダウンロードではパス要素を含む名前を受け付けず、受信ではパス要素を取り除く。どちらも解決後のパスが対象フォルダの直下にあることを確認する |
| **一覧の対象** | シンボリックリンク、隠しファイル（`.` で始まる名前、Windowsの隠し・システム属性、macOSの非表示フラグ）、フォルダ、受信中の `.part` は、一覧にもダウンロード対象にも含めない |
| **ファイル名** | Unicode NFC に正規化し、Windowsで使えない文字、予約名（`CON`、`NUL`、`COM1` など）、末尾のドットや空白を安全な形に直す |
| **サイズと空き容量** | `--max-size` を超えるファイルや、受信すると保存先の空き容量が256MBを下回りそうなファイルは受け付けない |
| **作っていないAPI** | ファイルを削除するAPIや、任意のパスを指定するAPIはない。「フォルダで表示」も、一覧にあるファイル名だけを受け付ける |
| **自動停止** | 無操作が続いたとき（既定30分）と、PCの画面を閉じたときに停止する。データの送受信が続いている間は停止しない |

QRコードやURLを知っている人は、誰でも接続できます。QRコードやターミナルの画面を他の人に見せたり、
URLを共有したりしないでください。LanDropを停止すると、そのURLは使えなくなります。

## 接続できないとき

まず、PCのブラウザでPCの画面の上部に表示された `http://<IPアドレス>:<ポート>/` を開いてください。
「QRコードから接続してください」と表示されれば、サーバーは正しく動いています。

| 確認すること | 対処 |
| --- | --- |
| **同じネットワークか** | スマホとPCが同じWi-Fi（同じルーター）につながっているか確認する。スマホがモバイルデータ通信になっていないかも確認する |
| **ゲストWi-Fi・端末どうしの遮断** | ゲスト用のSSIDや、ルーターの「プライバシーセパレーター」「端末間通信の遮断」が有効だと、端末どうしで通信できない。通常のSSIDにつなぐ |
| **スマホのVPN** | スマホでVPNを使っているとLANに届かないことがある。一時的にオフにする |
| **Windowsのネットワークの種類** | 起動時に「パブリック ネットワーク」の注意が出たら、自宅など信頼できるネットワークに限り、設定 > ネットワークとインターネット > Wi-Fi（またはイーサネット）> 接続中のネットワーク で「ネットワーク プロファイルの種類」を「プライベート」にする |
| **Windowsのファイアウォール** | Windows セキュリティ > ファイアウォールとネットワーク保護 > ファイアウォールによるアプリケーションの許可 で、LanDrop（Pythonから起動したときは Python）の「プライベート」にチェックが入っているか確認する |
| **macOSのファイアウォール** | システム設定 > ネットワーク > ファイアウォール > オプション で、LanDrop（または Python）への受信接続がブロックされていないか確認する |
| **アドレスが違う** | VPNや仮想アダプターのアドレスが選ばれていないか確認し、`--ip` で指定し直す。PCのアドレスは、Windowsなら `ipconfig`、macOSなら `ipconfig getifaddr en0`（Wi-Fiのとき）で調べられる |
| **WSLの中で起動している** | WSLではなく、Windowsで起動し直す |
| **QRコードが読めない** | PCの画面のQRコードを読み取る。ターミナルのQRコードを使うときは、文字を小さくしすぎず、Windowsでは Windows Terminal で表示する |
| **PCの画面が開かない** | ターミナル（黒い窓）に表示された「PCの画面」のURLを、このPCのブラウザで開く |
| **PCの画面を閉じたら止まった** | 仕様。PCの画面を閉じると、転送が終わってから停止する。続けて使うときは、もう一度起動する |
| **「接続が切れました」と表示される** | PCでLanDropが停止したか、再起動した。新しく表示されたQRコードを読み取る |
| **共有したファイルがスマホに出ない** | PCの画面の「共有中のファイル」に出ているか確認する。スマホの一覧は数秒ごとに更新される（「更新」でもすぐ読み込める）。フォルダの直下にあるファイルだけを表示し、フォルダ・隠しファイル・シンボリックリンクは表示しない |
| **ターミナルに「HTTPとして読めない接続」と出る** | ブラウザが `https://` で接続を試したときなどに出る。LanDropはHTTPだけで動くため、その接続は受け付けずに切断する。ブラウザはそのあとHTTPで接続し直すことが多いので、ページが開いていれば問題ない。開かないときは、アドレスが `http://` で始まっているか確認する |
| **iPhoneでSafari以外のブラウザを使っている** | 設定 > プライバシーとセキュリティ > ローカルネットワーク で、そのブラウザがオンになっているか確認する |

Windowsでネットワークの種類を確かめるだけなら、PowerShellで次の読み取り専用コマンドを使えます:

```powershell
Get-NetConnectionProfile | Select-Object InterfaceAlias, NetworkCategory
```

## 実機確認チェックリスト

ブラウザの実機での動作は、自動テストでは確認できません。iPhoneとAndroidで次の項目を確かめてください。

### iPhone（Safari）

## 開発

テスト用のパッケージを入れて、pytest を実行します:

```bash
python -m pip install -r requirements-dev.txt
python -m pytest
```

### デザインシステム

スマホの画面とPCの画面は、`landrop/static/ui.css` の同じ値と部品で作っています。値は3層に分け、
部品からは基本の値を直接使いません。

| 層 | 例 | 役割 |
| --- | --- | --- |
| **基本の値** | `--teal-700`、`--gray-50`、`--space-4`、`--radius-lg` | 色や長さそのもの |
| **意味の値** | `--color-primary`、`--color-surface`、`--color-danger` | 役割ごとの色。ダークモードではここだけを切り替える |
| **部品の値** | `--button-height`、`--card-radius`、`--tile-size` | 部品ごとの寸法と色 |

部品は `.btn`（`btn-primary`・`btn-ghost`・`btn-danger`・`btn-quiet`）、`.card`、`.chip`、`.badge`
（`data-tone` で色を変える）、`.tile`、`.file`、`.item`、`.progress`、`.empty`、`.notice`、`.message-card` です。
アプリのアイコン（`packaging/icon.png`）は `landrop/static/icon.svg` から作っています。

### API

APIは画面から使うためのものですが、curl などからも呼び出せます。認証後のCookieが必要です。

| メソッド | パス | 内容 |
| --- | --- | --- |
| **GET** | `/auth?t=<トークン>` | トークンを確かめてCookieを発行し、`/` へリダイレクトする |
| **GET** | `/api/info` | PC名、トークンを除いたアドレス、1ファイルの上限 |
| **GET** | `/api/files` | 共有フォルダのファイル一覧 |
| **GET** | `/api/files/{ファイル名}` | ファイルのダウンロード |
| **POST** | `/api/upload?name=<ファイル名>` | 本文にファイルのバイト列をそのまま送る（`Content-Length` が必要）。保存した名前を返す |

PCの画面用のAPIは、このPCの `127.0.0.1` からだけ使えます。

| メソッド | パス | 内容 |
| --- | --- | --- |
| **GET** | `/pc/auth?t=<PCの画面用トークン>` | PCの画面用のCookieを発行し、`/pc` へリダイレクトする |
| **GET** | `/pc/api/status` | PC名、スマホ用のURL、フォルダの場所、自動停止までの秒数 |
| **GET** | `/pc/api/files/{share または received}` | フォルダの一覧（受信フォルダは受信中のファイルも返す） |
| **POST** | `/pc/api/share?name=<ファイル名>` | 共有フォルダにファイルを追加する |
| **GET** | `/pc/preview/{share または received}/{ファイル名}` | 画像と動画を、画面内で表示する形で返す |
| **POST** | `/pc/api/reveal?folder=<フォルダ>&name=<ファイル名>` | エクスプローラー（Finder）でファイルを表示する |
| **POST** | `/pc/api/open-folder?folder=<フォルダ>` | フォルダを開く |
| **GET** | `/pc/api/events` | PCの画面が開いている間つないでおく接続。切れたら、画面が閉じられたとみなす |
| **POST** | `/pc/api/stop` | 停止する |

```bash
curl -c cookie.txt "http://192.168.1.10:8765/auth?t=<トークン>"
curl -b cookie.txt -X POST -T photo.jpg "http://192.168.1.10:8765/api/upload?name=photo.jpg"
```

## 今回対応していないこと

HTTPS、分割アップロードと途中からの再開、フォルダごとの送信やZIP圧縮、テキストの共有、ユーザー
アカウント、インターネット経由の接続、アプリへの署名（Windowsのコード署名・macOSの公証）には対応
していません。PCの画面から共有をやめる（ファイルを消す）操作はないため、「フォルダで表示」から
エクスプローラー（Finder）で削除してください。

送信中にスマホの画面を消したり別のアプリに切り替えたりすると、送信が止まって「失敗」になることが
あります。その場合は「再送」を押してください。電源が切れるなどしてPC側が強制終了したときは、受信
フォルダに `.*.landrop-*.part` が残ることがあります。不要であれば削除してください。
